React + Webpack 開發環境建立教學

github 載點

官方的 npx create-react-app my-app 現已改為使用 Vite + Rollup，不再倚賴 Webpack。
不過若你對 Webpack 打包流程更熟悉，仍可手動建立 React 專案。

為什麼使用 Webpack？

使用 Webpack 的目的：

  1. 安裝 Webpack 並自訂設定檔
  2. 使用 Babel 編譯 React 的 JSX 語法
  3. 打包 JS、HTML、CSS 等檔案
  4. 利用 dev server 啟用 hot reload
